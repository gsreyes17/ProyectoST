# Documentación local

Esta carpeta reúne guías operativas y notas de trabajo que no forman parte del
contrato principal de arquitectura o IAM. No debe contener contraseñas,
claves, tokens, volcados de bases ni otros secretos.

## Guías

- [DBeaver y autorización de la interfaz](dbeaver-y-autorizacion-ui.md):
  conexión local a PostgreSQL, diagramas de esquema y diseño recomendado para
  controlar vistas, botones y columnas según el rol.

Las guías de esta carpeta asumen la instalación descrita en el
[README principal](../../README.md).
